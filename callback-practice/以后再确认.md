# 以后的五笔部署

现在不要运行下面任何一条。每一笔都要先重新读余额，再在聊天里单独说可以，然后由你自己执行这一笔。钥匙用已经导入的 `lasna`。不要再导出私钥，不要把密码发到聊天。如果终端索要钥匙库密码，只在 Ubuntu 里输入。

不要使用官方脚本里的 `PRIVATE_KEY`，不要创建 `.env`。

2026-11-22 只读快照，发送前会变，不能当作届时余额：

- Lasna 钱包：`0.887844499999378445` lREACT
- Sepolia 钱包：`0.039962792499603120` ETH
- 已部署的 Xfers `0x298c78B4d1F0ecAb2b4cD2D477a1abCD4C2d32e6`：`_limit()` 为 0，合约里还剩约 `0.0441384` lREACT。那是旧练习的合约余额，不是钱包余额。

源链和目标链都是 Ethereum Sepolia（链 id `11155111`）。Callback Proxy 用官方当前地址 `0xAa14d9Cd0f788Ca23d11805986C1d8bd035D23b4`。2026-11-22 读到它有 218 字节代码，与 [Origins & Destinations](https://dev.reactive.network/origins-and-destinations) 一致。

官方金额进的是合约 balance。reserves 为 0 时，系统或 Callback Proxy 会调用 `pay()`，从这份余额扣费。`0.5` lREACT 和 `0.02` ETH 都不是 `depositTo`。

## 第 1 笔：Sepolia 部署事件源

只付 Sepolia gas，不附带金额。

```bash
cd ~/reactive-camp-work/callback-practice
forge script script/Deploy.s.sol:DeployOrigin \
  --rpc-url https://ethereum-sepolia-rpc.publicnode.com \
  --chain 11155111 \
  --account lasna \
  --broadcast
```

记下 `ORIGIN_ADDR`。

官方默认再附带 `0.5` lREACT 进新合约，部署 gas 另从钱包扣。以今天的快照，钱包大约 `0.89` lREACT，付得起这一笔，但必须先重读。


```bash

ORIGIN_ADDR=这里换成上一笔的地址 \

  --rpc-url https://lasna-rpc.rnk.dev/ \
```

## 第 3 笔：Sepolia 部署回调合约

官方默认附带 `0.02` ETH 进回调合约，gas 另付。今天的 Sepolia 快照只有约 `0.040` ETH。第 1 笔花掉 gas 之后，`0.02` 可能就紧。发送前重读，不够就停，不要把金额改大。

```bash
cast balance 0xfc118609d291391df2eA4975d39866256d47f5AA --rpc-url https://ethereum-sepolia-rpc.publicnode.com --ether
```

确认后：

```bash

REACTIVE_ADDR=这里换成第2笔的地址 \
```

记下 `CALLBACK_ADDR`。构造参数填错只能重新部署。

## 第 5 笔：Sepolia 发出 Ping

`value` 用 500，大于阈值 100。这笔自己只付 Sepolia gas。随后 Lasna 的 react 从第 2 笔的合约余额扣 lREACT，Sepolia 的回调从第 3 笔的合约余额扣 ETH。回调失败也会扣回调合约的 ETH。

```bash
cd ~/reactive-camp-work/callback-practice
ORIGIN_ADDR=第1笔地址 \
PING_VALUE=500 \
forge script script/Deploy.s.sol:Ping \
  --rpc-url https://ethereum-sepolia-rpc.publicnode.com \
  --chain 11155111 \
  --account lasna \
  --broadcast
```

等一两分钟后，把三个地址写进 `env.public`（从 `env.public.example` 复制，不要写密钥），再运行 `bash script/verify.sh`。它只查询。三条链接分别是：Sepolia 的 Ping 交易、Lasna 的 react 交易、Sepolia 的 Handled 交易。
